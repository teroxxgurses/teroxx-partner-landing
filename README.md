# Teroxx Partner Landing Page

Moderne Lead-Generierungs-Landingpage für Finanzberater-Partner von Teroxx.

## Features

✅ **Mobile-First Optimized** - Perfekt für Instagram Ads  
✅ **60-Sekunden Qualification Flow** - Schnelle Lead-Erfassung  
✅ **Premium Design** - Blau + Golden Hour Farben  
✅ **Meta Pixel Integration** - Automatisches Ad Tracking  
✅ **GDPR-konform** - Datenschutz garantiert  
✅ **Vercel-Ready** - Automatisches Deployment

```bash
# Dependencies installieren
